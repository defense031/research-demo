# research-demo

Demo projects from the Department of Mathematical Sciences, United States Military Academy.
Each project lives in its own folder. Click a **live** link to open the page in your browser;
the folder link shows the source files.

| Project | Live | Source |
|---|---|---|
| Agents for Research (talk) | [open the deck](https://defense031.github.io/research-demo/talks/agents-for-research/agents_for_research.html) | [talks/agents-for-research](talks/agents-for-research) |
| Support vector machines and the kernel trick | [open the deck](https://defense031.github.io/research-demo/demos/svm-rings/) | [demos/svm-rings](demos/svm-rings) |

The live pages are served by GitHub Pages from this repo's `main` branch. A link to a folder
that has not been pushed yet shows a 404 page until it is.
