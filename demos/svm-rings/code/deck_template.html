The problem
  • Data: points on two noisy rings, one inside the other
  • Split: points train the SVM; held-out points test it
  • Best straight line: a linear SVM rates % of held-out points correctly, close to a coin flip
  • Every line leaves part of the inner ring on the outer ring's side
Lift to 3D
  • Give every point a height: φ(x1, x2) = (x1, x2, x12 + x22)
  • Points far from the center rise higher, so the outer ring sits above the inner ring
  • A flat plane now separates them. A linear SVM on the lifted points rates % of held-out points correctly
Back to 2D
  • The plane cuts the bowl in a circle, so the boundary in 2D is a circle
  • Only support vectors set that boundary

The kernel trick

A kernel K(x, x′) = φ(x) · φ(x′) gives the SVM this lift without computing φ.
